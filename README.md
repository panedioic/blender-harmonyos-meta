## 📦 迁移说明

原 Meta 仓库（多仓库导航、构建脚本、打包发布说明等）已随项目迁移并**归档**。后续的**代码开发、问题跟踪、构建发布**均在新仓库进行，请以新仓库为准。

**迁移原因**：
- **方便开发**：原多仓库拆分的 Meta 结构不利于日常开发与调试，统一到一个仓库后，代码、脚本、文档集中管理，开发效率更高；
- **方便同步上游**：新仓库基于 Blender 官方仓库组织，可以**直接跟进上游 Blender 的修改与更新**，减少手工合并成本，保持与上游同步；
- **统一发布流程**：构建产物、安装包（`.hap`）与文档在同一处发布，使用和反馈更清晰。
